# 手动测试清单

玩家或开发者装好 dev 构建产物后，按本清单逐项验证。每项都写清「怎么看到」和「预期」。

## 一、安装

1. 装 Minecraft 1.21.1 + NeoForge 21.1.265+。
2. 装 Thaumaturge 1.1.0+（required，缺它进不了世界）。
3. 把本模组 jar 放进 `mods/`。
4. 进任意世界。本模组纯客户端，单人 / 多人皆可，服务端无需安装。

## 二、启动检查

- [ ] 模组列表里出现「Thaumaturge Aspect Tooltip」，无红字、无加载错误。
- [ ] 日志无 `thaumaturge_aspect_tooltip` 相关的异常栈。
- [ ] 原版物品 tooltip 正常，没有被本模组改动。

## 三、核心用例

对照 Thaumaturge 本体已确认的行为（本体只对源质容器与 `ILabel` 物品输出文本，样本见整合包里的
「秩序 魔力水晶碎片」；其余物品原本只有 Shift 图形 Chip）：

| 用例 | 操作 | 预期 |
|---|---|---|
| U1 无文本行、有要素 | 悬停有要素数据、本体不显示文本的物品 | 物品名下方多出「要素：」表头，逐条要素行，数量多的在前 |
| U2 已有文本行 | 悬停本体已显示「要素：…」的物品（魔力水晶碎片、魔力安瓿、魔豆） | 只有一组要素行，不重复、不叠字、顺序不变 |
| U3 Shift 图形版 | 悬停物品并按住 Shift | 本体 Chip 图标正常出现，本模组不追加、不遮挡 |
| U4 无要素数据 | 悬停原版石头、木板等 | tooltip 无任何新增要素行 |
| U5 数量与多要素 | 悬停含多种要素、数量不同的物品 | 每种要素各一行，名称与数量对应正确，顺序与按住 Shift 的图标一致（数量多的在前） |
| U6 本地化 | 切换游戏语言到中文 / 英文 | 文本行随语言切换，无 key 直显（如 `tooltip.aspect`） |
| U7 容器与 JEI | 在箱子、JEI/EMI 里悬停物品 | tooltip 行为与背包内一致 |

## 四、回归检查

- [ ] 装了 Jade / WTHIT 之类 tooltip 增强时，本模组的行不与它们的输出冲突。
- [ ] 服务端未装本模组时，客户端能正常进服（纯客户端功能）。

## 五、失败记录格式

发现问题时按下面格式记进 issue，附截图：

```
用例编号：U?
游戏 / 加载器 / 模组版本：
Thaumaturge 版本：
物品与取得方式：
实际表现：
预期表现：
日志片段：
```
